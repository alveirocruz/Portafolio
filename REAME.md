# Portafolio Web — Yeison Alveiro Cruz Moreno

Sitio web personal para mostrar mi perfil como desarrollador Full Stack Java, mis proyectos y mi información de contacto.

🔗 **Demo en vivo:** [alveirocruz.github.io/Portafolio](https://alveirocruz.github.io/Portafolio/)

## 📋 Descripción

Portafolio profesional construido con HTML, CSS y JavaScript puro (sin frameworks). Incluye una sección de presentación, estudios, tecnologías, proyectos destacados y formas de contacto directo (email, teléfono, WhatsApp).

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- [Devicon](https://devicon.dev/) para los íconos de tecnologías

## ✨ Características

- Diseño responsive (adaptado a móvil, tablet y escritorio)
- Menú de navegación con scroll suave y menú hamburguesa en móvil
- Sección de estudios con estado (en curso / finalizado)
- Tarjetas de proyectos con stack tecnológico y funcionalidades
- Botón flotante de contacto por WhatsApp
- Descarga directa de CV en PDF

## 📁 Estructura del proyecto

```
Portafolio/
├── index.html          # Estructura principal del sitio
├── style.css            # Estilos
├── app.js                # Scroll suave y menú móvil
├── Imagen1.jpeg          # Foto de perfil
├── CV-Yeison_Cruz.pdf     # Hoja de vida descargable
└── README.md
```

## 🚀 Cómo verlo localmente

1. Clona el repositorio:
   ```bash
   git clone https://github.com/alveirocruz/Portafolio.git
   ```
2. Entra en la carpeta y abre `index.html` en tu navegador (no requiere servidor ni instalación de dependencias).
